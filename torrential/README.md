# Home Assistant App: torrential

[torrential](https://github.com/nexxeln/torrential) finds films and shows and
plays them on your phone, computer or TV while they download. This app runs
its engine as a server on Home Assistant. Optional built-in Cloudflare Tunnel
and Tailscale Serve/Funnel publish it without opening ports.

Supports `aarch64` (Home Assistant Green, Yellow, Raspberry Pi 4/5) and `amd64`.

See [DOCS.md](DOCS.md) for setup.
